# Teaching

Teaching materials.

| Folder | Contents |
|---|---|
| [PySoc/](PySoc/) | Two Colab notebooks on how a climate model computes radiation, and climate experiments with it, built on [PySoc](https://github.com/evanwellmeyer/PySoc) |
| [ai_weather_lab/](ai_weather_lab/) | Colab notebooks in which students run and perturb AI weather models: NeuralGCM (including a lab built around a weather event each student chooses), and Pangu-Weather, FourCastNet and DLWP through Earth2Studio |
| [ml_play/](ml_play/) | Colab notebooks for exploring ERA5 with machine learning: Fourier analysis of the Niño 3.4 index, EOFs and spherical harmonics of ERA5 fields, and a small CNN that predicts tomorrow's Z500 from today's |
